## 🗂️ Como este repositório está organizado

A organização aplica os conceitos de Arquitetura da Informação vistos na Aula 5 de Gestão da Informação.

- **Classificação:** o conteúdo é agrupado por matéria, e o Projeto Integrador .
- **Taxonomia:** estrutura simples em dois níveis, `matéria -> README`, com nomes padronizados.
- **Metadados:** cada README de matéria começa com uma tabela com matéria, semestre, categoria, palavras-chave e relações.
- **Navegação:** o README principal leva a cada matéria, e todas têm link para voltar ao início.
- **Encontrabilidade:** nomes claros e sem acento, descrição e tópicos configurados no repositório e palavras-chave nos metadados.
- **Relações entre conteúdos:** o campo "Relacionado a" liga as matérias entre si (veja abaixo).
